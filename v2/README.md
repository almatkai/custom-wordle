# Custom Wordle — Native V2 Rust

Offline Rust implementation of the own V1 command at `5c7c4792f534a45001e7b71b1b41ead825914f80`. V1 remains beside this directory; its tracked bytes are unchanged except for the root README discovery link. Original Raycast author: **pallav_agarwal**. The original manifest lists no contributors. Own V1 maintainer: **almatkai**. See [NOTICES.md](NOTICES.md) and [provenance.json](provenance.json).

`create-custom-wordle` / **Create Custom Wordle** accepts one required text argument, `word` (“Word to be guessed”). There are no source form fields, preferences, launch flags, history, or persistent keys. “Share” means copy the generated link; the source has no separate share-sheet action.

The engine follows the actual own source: ECMAScript trim, lowercase, reject empty input, reject non-ASCII letters (with the original spaces-vs-letters error priority), then the source's repeating `wordle` obfuscation and exact fixed `https://mywordle.strivemath.com/?word=` serialization. There is no generic five-letter restriction, percent encoder, Base64, dictionary check, API request, or site-content dependency. Unicode Kelvin sign lowercases to `k`; other non-ASCII content is validated according to source results. UTF-16 tests include every individual code unit and lone surrogates. The typed Rust API exposes `generate_utf16`; the host JSON transport may reject malformed surrogate escapes before reaching the adapter.

The explicit resource limit is **1,048,576 input UTF-16 code units before trimming**. Larger input returns an error, never a truncated word or URL. The source has no such explicit limit. Normal operation uses only Rust and the beta SDK; Node and the vendored locked TypeScript compiler are validation tools.

`adapter.rs` is a concrete production adapter, compiled against unchanged beta `common.rs`, `v2_sdk.rs`, and `NativeSessions` from `fd300e276356587726566026f072563eb9c34cb1`. Copy uses `sdk::copy` → `clipboard:write [url]`; explicit Open Link uses `sdk::open` → `shell:open [url]`. Both require object acknowledgements with `ok: true`, `error` absent/null and `success` absent/true. Private router errors are replaced with fixed public messages. No event-provided URL, output, arguments or preferences can redirect an action.

The beta SDK has no genuine HUD/toast primary-action API. A native Detail result preserves the source's copy-first ordering and **Open Link** primary action after confirmed copying. **Copy Link** permits another deliberate copy. Copy/open failures are reported as unconfirmed; refresh never repeats an effect, and the user may choose an explicit retry. Source `Clipboard.copy` is unawaited and can announce success despite an asynchronous clipboard failure; V2 intentionally waits for acknowledgement. A pending checkpoint survives dropped futures and retains earlier confirmed effects. No hide, paste, selection, focus, or pop-to-root behavior is invented.

Session capabilities use a process nonce and monotonic counter. Valid completed actions rotate them; malformed, forged, stale and cross-session calls fail without consuming a valid action. Search/load-more return unchanged without minting IDs or mutating staged clones. Idle refresh is unchanged; uncertain-effect refresh renders the same IDs and never performs the effect. Disposal clears session data. There is no source persistence to migrate; the adapter never reads legacy storage. Unknown SDK storage keys and corruption are tested separately against the real SDK.

The exact original 19,722-byte PNG is retained at `assets/custom-wordle-icon.png`, SHA-256 `d4033620dc53983df5721e784708f14c93d5fdc84ba64f882a14c71566278705`. It must be copied unchanged to the host's `src/renderer/public/extensions/icons/custom-wordle.png`; the schema-2 URL is `/extensions/icons/custom-wordle.png`.
